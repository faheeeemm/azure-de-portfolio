## 🧠 Key Concepts Faheem Has Understood Well
- Variables as labels pointing to memory, not boxes holding values
- Garbage collection — labels removed, GC cleans up later
- Why None exists — intentional absence of value, not zero or empty
- Defensive coding — catching specific exceptions, never bare except
- Why return > print in pipeline code
- Decorator pattern — wrapper + return wrapper + @wraps
- Inheritance reduces code redundancy — parent blueprint, child extends
- Sets for deduplication and incremental processing patterns
- List comprehensions as collapsed for loops with filter
